# Дизайн: Экстренный вход с подтверждением и временное отключение защиты

## 1. Контекст и цели
Пользователю необходима возможность:
1. **Экстренный вход (Emergency Access)** во время фаз вдоха и выдоха:
   - Пропустить таймер осознанности и сразу открыть целевое приложение.
   - Защита от импульсивных случайных нажатий: диалог подтверждения «Вы уверены?».
2. **Временное отключение защиты (Pause Protection)**:
   - На 15 минут, 30 минут, 60 минут или до ручного включения (бессрочно).
   - Возможность выбрать отключение прямо в окне подтверждения экстренного входа (для текущего приложения).
   - Возможность глобальной приостановки всей защиты на `HomeScreen` с таймером обратного отсчета и кнопкой немедленного возобновления.

---

## 2. Архитектура и модель данных

### 2.1. Доменная логика и правила (`RuleEngine.kt`)
- В `RuntimeState`:
  - Добавляется поле `val protectionPausedUntil: Long? = null` (timestamp в миллисекундах, где `-1L` означает паузу до ручного включения).
- В `RuleEngine.evaluate`:
  - Проверка наивысшего приоритета:
    ```kotlin
    if (state.protectionPausedUntil != null) {
        if (state.protectionPausedUntil == -1L || now.toEpochMilli() < state.protectionPausedUntil) {
            return Decision.Allow
        }
    }
    ```
- Для по-приложенного отключения:
  - Используется механизм `AccessGrant(packageName, grantedAt, expiresAt)`.
  - При выборе «Отключить на 15м/30м/60м» создается `AccessGrant` на соответствующее количество миллисекунд.
  - При выборе «До включения» целевое приложение переводится в состояние `enabled = false` (либо постоянный грант).

### 2.2. Репозиторий и хранилище (`RonesecRepository.kt`)
- `getProtectionPausedUntil(): Long?` / `getProtectionPausedUntilFlow(): Flow<Long?>`
- `pauseProtection(durationMinutes: Int)` (вычисляет timestamp окончания, либо `-1L` для бессрочной паузы)
- `resumeProtection()` (удаляет или обнуляет ключ `protection_paused_until`)
- Метод `emergencyGrantAccess(packageName: String, durationMs: Long?, disableTarget: Boolean)`

## 3. Пользовательский интерфейс (UI)

### 3.1. Оверлей интервенции (`InterventionOverlayView.kt` и `OverlayController.kt`)
- Внизу экрана под кнопкой «ВЫЙТИ» отображается кнопка «⚡ ЭКСТРЕННЫЙ ВХОД».
- При нажатии открывается диалоговое окно подтверждения:
  - Текст: «Вы уверены? Пауза осознанности будет пропущена.»
  - Кнопка «ВОЙТИ РАЗОВО» (мгновенно открывает приложение).
  - Секция «ПРИОСТАНОВИТЬ ЗАЩИТУ ДЛЯ ПРИЛОЖЕНИЯ»:
    - Чипы: `15м`, `30м`, `60м`, `До включения`.
  - Кнопка «ВЕРНУТЬСЯ К ДЫХАНИЮ».
- Callbacks в `InterventionOverlayContent`:
  - `onEmergencyAccess: (durationMs: Long?, disableTarget: Boolean) -> Unit`

### 3.2. Главный экран (`HomeScreen.kt`)
- Карточка «СТАТУС ЗАЩИТЫ»:
  - Когда защита активна:
    - Кнопки быстрой паузы: `15м`, `30м`, `1ч`, `До включения`.
  - Когда защита приостановлена:
    - Баннер «ЗАЩИТА ПРИОСТАНОВЛЕНА».
    - Таймер обратного отсчета оставшегося времени (или надпись «До ручного включения»).
    - Кнопка «ВОЗОБНОВИТЬ ЗАЩИТУ».
