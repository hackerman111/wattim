# Дизайн: Ввод минут в расписании блокировки

## 1. Контекст и цель
Пользователю необходима возможность задавать точное время начала и окончания расписания блокировки с точностью до минут (например, `09:30`).
Ранее в UI диалога создания расписания (`AddScheduleDialog`) присутствовали только кнопки шага по часам (`-1ч` / `+1ч`). В базе данных и логике (`BlockScheduleEntity`, `RuleEngine`, `LocalTime`) поддержка минут уже полностью реализована.

## 2. Архитектура UI компонентов
В AddScheduleDialog в BlocksScreen.kt секция времени разделяется на две секции: **НАЧАЛО** и **КОНЕЦ**.

Для каждого времени:
1. **Поле «ЧАСЫ» (0..23)**:
   - Текстовое поле ввода BasicTextField (макс. 2 цифры, фильтр `isDigit()`).
   - Кнопки степперов: `[-1ч]`, `[+1ч]`.
   - `imeAction = ImeAction.Next`, фокус переходит к полю минут.
2. **Поле «МИНУТЫ» (0..59)**:
   - Текстовое поле ввода BasicTextField (макс. 2 цифры, фильтр `isDigit()`).
   - Кнопки степперов: `[-5м]`, `[-1м]`, `[+1м]`, `[+5м]` с циклическим изменением (0..59).
   - `imeAction`: для начала `Next` (переход к часам конца), для конца `Done` (сброс фокуса и скрытие клавиатуры).
3. **Управление фокусом и кареткой**:
   - Использование `LocalFocusManager` и `LocalSoftwareKeyboardController`.
   - Поддержка `onKeyEvent` с `Key.Enter` для сброса фокуса.
   - Снятие фокуса при нажатии на любые кнопки-степперы и быстрые пресеты диапазонов.
4. **Валидация**:
   - При потере фокуса / сохранении: пустые значения нормализуются в "00", часы ограничиваются `0..23`, минуты `0..59`.

## 3. План тестирования
