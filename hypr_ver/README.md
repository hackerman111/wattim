# wattim для Hyprland

Анти-думскроллинг демон для оконного менеджера Hyprland: перемешивает окна охраняемых приложений на случайный рабочий стол, как только вы переключаетесь на другую задачу.

## Принцип работы
1. Вы работаете в охраняемом приложении (например, Telegram на рабочем столе 2).
2. Вы переключаетесь на браузер (например, на рабочий стол 4) или на пустой рабочий стол.
3. Демон мгновенно фиксирует уход фокуса и бесшумно (`movetoworkspacesilent`) отправляет окно Telegram на случайный рабочий стол из выбранного вами списка разрешённых столов.
4. Внутренние окна и диалоги (тот же класс окна) защищены от случайного перемешивания во время работы.

## Установка и сборка

```bash
cd hypr_ver
cargo build --release
```

Бинарник появится в `hypr_ver/target/release/wattim`. Вы можете скопировать его в `~/.local/bin/` или `/usr/local/bin/`:

```bash
cp target/release/wattim ~/.local/bin/
```

## Использование

### 1. Интерактивная настройка и отмена выбора
Просто введите в терминале:
```bash
wattim
```
* **Выбор и отмена рабочих столов**:
  - Список доступных столов (активные столы + диапазон 1..10).
  - Нажатие **Пробела** ставит или **снимает отметку (отменяет выбор)** со стола.
* **Выбор и отмена приложений**:
  - Если ранее приложения уже выбирались, сначала открывается список текущих приложений, где пробелом можно снять выбор с ненужных.
  - При добавлении новых приложений работает автодополнение по **Tab**.
  - Чтобы отменить выбор конкретного приложения, введите его имя с минусом (например: `-telegram-desktop`).
  - При повторном вводе уже выбранного приложения программа предложит отменить его выбор.
* **Отмена настройки целиком**:
  - В любой момент нажатие клавиши **Esc** или **Ctrl+C** отменяет процедуру без изменения конфигурации.
  - В конце выводится финальное подтверждение `Сохранить настройки и применить к демону?`, где можно отказаться от сохранения.
* При сохранении фоновый демон **автоматически перезапускается**.

### 2. Управление демоном и автозапуск

В `~/.config/hypr/hyprland.conf`:
```ini
exec-once = wattim start
```

Команды CLI:
* `wattim start` — запустить демон в фоне.
* `wattim stop` — остановить фоновый демон.
* `wattim restart` — перезапустить демон с новыми настройками.
* `wattim status` — проверить, запущен ли демон, и посмотреть текущий конфиг.
* `wattim run` — запустить в foreground (удобно для отладки и просмотра логов переключения).
* `wattim --help` — справка по командам.

## Логи и конфигурация
* Конфигурация: `~/.config/wattim/config.toml`
* PID процесса: `~/.config/wattim/wattim.pid`
* Логи фонового процесса: `~/.config/wattim/wattim.log`
