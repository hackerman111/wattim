## Что это такое

**wattim** — легковесный инструмент для прерывания импульсивных открытий социальных сетей и развлекательных ресурсов (open-source альтернатива *one sec*).

Приложение не блокирует сервисы намертво — оно внедряет контролируемое трение (friction). При запуске выбранного приложения или сайта поверх экрана накладывается полноэкранный оверлей с дыхательным циклом («Вдох → Задержка → Выдох → Покой»). Короткая задержка прерывает автоматический рефлекс и дает возможность осознанно решить: действительно ли вам нужен этот контент прямо сейчас.

### Структура репозитория

Проект организован как монорепозиторий с двумя независимыми клиентами:
- **`app/`** — нативное Android-приложение (Kotlin, Jetpack Compose, Room, Accessibility Service, `WindowManager` оверлей).
- **`extension/`** — браузерное расширение для Chromium-браузеров и Firefox (Manifest V3, закрытый Shadow DOM оверлей без перезагрузки страниц, чистый Vanilla JS без сторонних рантаймов).

## Механика работы

```
[Пользователь открывает целевое приложение / сайт]
                        │
                        ▼
            Детекция запуска / навигации
                        │
                        ▼
          ┌───────────────────────────┐
          │     Экран интервенции     │
          │ (60 FPS дыхательный цикл) │
          └─────────────┬─────────────┘
                        │
             ┌──────────┴──────────┐
             ▼                     ▼
        [ ВЫЙТИ ]           [ ПРОДОЛЖИТЬ ]
   (Мгновенный возврат     (Доступ открывается только
   на домашний экран /     после завершения полного
    закрытие вкладки)         цикла дыхания)
```

1. **Перехват**: фоновый монитор перехватывает смену активного окна на Android или навигацию по вкладкам в браузере.
2. **Интервенция**: поверх контента отрисовывается анимация дыхания. Интерактивные элементы страницы/приложения блокируются, медиапотоки заглушаются.
3. **Выбор**:
   - Кнопка **«Выйти»** доступна мгновенно на любой секунде — возвращает на домашний экран или закрывает вкладку, сохраняя успешную попытку сдерживания в локальную статистику.
   - Кнопка **«Продолжить»** активируется только по завершении таймера паузы.
4. **Сторож сессии (Re-intervention)**: если после входа вы проводите в сервисе больше установленного времени (например, 15 минут), интервенция активируется повторно.

## Возможности

### Экспоненциальное сдерживание (Exponential Backoff)
При частых повторных попытках открыть сервис в течение заданного окна (по умолчанию 1 час) время задержки прогрессивно растет:

$$T = T_{\text{base}} \times \left(1 + \frac{r}{100}\right)^N$$

где:
- $T_{\text{base}}$ — базовая длительность паузы (по умолчанию 10 сек);
- $r$ — шаг прироста в процентах (по умолчанию 20%);
- $N$ — номер повторного открытия за текущий интервал.

| Попытка ($N$) | Задержка (база 10 с, прирост 20%) |
| :---: | :--- |
| **1-я** | 10.0 с |
| **2-я** | 12.0 с |
| **3-я** | 14.4 с |
| **4-я** | 17.3 с |
| **5-я** | 20.7 с |
| **10-я** | 51.6 с |

В настройках доступен предпросчет задержек для первых 10 шагов.

### Режимы блокировок и расписания
- **Hard Block (Полная блокировка)**: запрет открытия приложений в указанные интервалы (например, в рабочие часы или ночью) без возможности входа через дыхание.
- **Custom Intervention (Персональная пауза)**: индивидуальная длительность паузы и частота повторного перехвата для конкретного приложения или домена.
- **Дни недели и минуты**: поддержка точного времени до минут (`09:30` → `18:15`) и произвольных комбинаций дней недели.

### Экстренный доступ и глобальная пауза
- **Разовый пропуск**: быстрое подтверждение для критических ситуаций, когда зайти нужно без ожидания.
- **Временное отключение**: пауза защиты для отдельного приложения или всей системы на **15 минут**, **30 минут**, **1 час** или **до ручного включения**.
- **Опциональная двухэтапная разблокировка**: код создаётся для одной intervention-сессии, вручную просматривается во вкладке **Коды** и вводится перед началом дыхания. Длина кода настраивается отдельно для приложения.
- **Опциональный код экстренного доступа**: доступ на заданное время можно подтвердить отдельным 10-значным кодом с intervention-screen.
- **Виджет обратного отсчета**: статусная панель на главном экране с живым таймером и кнопкой мгновенного возобновления защиты.

### 6 терминальных тем
В обоих клиентах реализована единая система тем:
- `Nord` — арктическая палитра с холодными оттенками.
- `Catppuccin Mocha` — контрастная пастельная темная тема.
- `Dracula` — темная тема с акцентами пурпура и бирюзы.
- `Gruvbox Dark` — ретро-терминал с теплыми бежевыми и оранжевыми тонами.
- `Tokyo Night` — неоновые киберпанк-акценты на темном фоне.
- `Cyber Terminal` — классическая монохромная зеленая консоль.

### 5 стилей 60 FPS Canvas-анимации
- **Pulse**: сферический пульсар с фазами вдоха и выдоха.
- **Fill**: сплошная плавная волна заливки по вертикали.
- **Zen Orbit**: частица на круговой орбите с изменяющимся радиусом.
- **Wave**: непрерывная атмосферная волна без отображения прогресса и оставшегося времени.
- **Fill 2**: плавная заливка без таймера со случайными колебаниями уровня вверх и вниз.

## Приватность и безопасность

- **0 сетевых запросов**: в `AndroidManifest.xml` отсутствует разрешение `android.permission.INTERNET`. Приложение физически изолировано от сети.
- **Без телеметрии и трекеров**: отсутствуют Firebase, Google Play Services, Crashlytics, AppMetrica и рекламные SDK.
- **Изолированное локальное хранилище**:
  - Android: база данных SQLite через Room (`app/data/local/`).
  - Браузер: `chrome.storage.local`, данные не синхронизируются с внешними серверами.
- **Компактность**: релизный Android APK оптимизирован через R8 и весит всего **2.4 МБ**.

## Android-клиент

### Требования
- Android 10.0+ (API 29+)
- Архитектуры: ARM64, ARMv7, x86_64

### Необходимые разрешения
Для надежной и приватной работы требуются следующие разрешения:
1. **Служба специальных возможностей (Accessibility Service)** — использует адаптивную фильтрацию событий (`TYPE_WINDOW_STATE_CHANGED`) для детекции запуска выбранных пакетов. Не читает экранный текст, пароли и не перехватывает ввод.
2. **Отображение поверх других приложений (SYSTEM_ALERT_WINDOW)** — требуется для вывода полноэкранного Jetpack Compose оверлея поверх целевого приложения (`TYPE_APPLICATION_OVERLAY`).
3. **Фоновая служба (FOREGROUND_SERVICE_SPECIAL_USE)** — обеспечивает непрерывную защиту и управление временным аудиофокусом без изменения глобальной громкости (Android 14+).
4. **Уведомления (POST_NOTIFICATIONS)** — постоянное низкоприоритетное системное уведомление о статусе защиты (Android 13+).
5. **Видимость пакетов (QUERY_ALL_PACKAGES)** — возможность выбрать любое установленное пользователем приложение для защиты.

### Установка готового APK
1. Загрузите файл [wattim.apk](./wattim.apk) на устройство.
2. Разрешите установку из внешних источников.
3. При первом запуске предоставьте запрашиваемые разрешения в мастере начальной настройки.

> **Примечание (Google Play Защита и Android 13+):**  
> Google может предупреждать о неизвестном разработчике или подозрительном поведении из-за механики отображения оверлея поверх других окон. При этом wattim полностью изолирован от сети (разрешение `INTERNET` отсутствует).  
> Если переключатель службы спец. возможностей не нажимается («Ограниченная настройка»):  
> `Настройки Android` → `Приложения` → `wattim` → меню вверху справа `(⋮)` → **«Разрешить ограниченные настройки»**.

## Браузерное расширение

Совместимо с Chromium-браузерами (Chrome, Brave, Edge, Vivaldi, Яндекс) и Firefox.

### Архитектура оверлея
- **Shadow DOM (`mode: "closed"`)**: оверлей внедряется прямо в страницу и полностью изолирован от ее стилей и скриптов.
- **Без перезагрузки страниц**: при нажатии «Продолжить» оверлей удаляется из DOM, мгновенно возвращая управление странице без потери несохраненного состояния.
- **Глушение медиа**: во время дыхания аудио- и видеоэлементы страницы автоматически ставятся на паузу.

### Установка в Chromium (Chrome, Brave, Edge)
1. Откройте `chrome://extensions` (или `brave://extensions` / `edge://extensions`).
2. Включите **«Режим разработчика»** (Developer mode).
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
4. Укажите путь к папке `extension/` в этом репозитории.

### Установка в Firefox
1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите кнопку **«Загрузить временное дополнение...»** (Load Temporary Add-on).
3. Выберите файл `extension/manifest.json`.

```
.
├── app/                              # Android-приложение (Kotlin + Jetpack Compose)
│   ├── src/main/
│   │   ├── AndroidManifest.xml       # Манифест приложения (без доступа в сеть)

│   │       ├── service/              # AppMonitorService (Accessibility Service)
│   │       └── ui/                   # Jetpack Compose экраны (M3), темы, компоненты
│   └── src/test/                     # Модульные и приемочные тесты
│
├── extension/                        # Браузерное расширение (Manifest V3, Vanilla JS)
│   ├── manifest.json                 # Декларация расширения (Chromium + Firefox)
│   ├── background/                   # Service worker и логика RuleEngine
│   ├── overlay/                      # Контентный скрипт и Shadow DOM инжектор
│   ├── intervention/                 # Дыхательный экран и 60 FPS Canvas-анимации
│   ├── sentinel/                     # Фоновый монитор времени на странице
│   ├── popup/                        # Быстрое всплывающее меню управления
│   └── options/                      # Страница настроек, списки сайтов, расписания
│
├── tests/                            # Тестовый набор расширения (Node.js)
│   ├── test-rule-engine.mjs          # Тесты логики перехватов и бэкоффа
│   ├── test-storage.mjs              # Тесты миграций и хранилища
│   └── run-all.mjs                   # Сводный тестовый раннер
│
├── wattim.apk                        # Собранный релизный APK (2.4 МБ)
└── build.gradle.kts                  # Корневой скрипт сборки Gradle
```
